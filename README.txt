【皮膚科英単語 PWA・編集機能付き】

今回の版では、iPhoneの画面から単語を
・追加
・編集
・削除
・検索
できるようにしました。

使い方：
1. GitHub Pages の既存Repositoryで index.html と sw.js をこの版に置き換える
2. iPhoneでページを開く
3. 「📝 単語を追加・編集・削除」から管理
4. 追加・編集・削除した内容は、そのiPhoneのブラウザ内に保存されます

重要：
・GitHub上の data.json は変更されません。
・したがって、編集内容はこのiPhone専用です。
・バックアップしたい場合は「現在の単語帳をCSV保存」を使ってください。
・CSV読み込みは現在の単語帳を置き換えます。
・GitHub Pagesの更新後、古いPWAが表示される場合はSafariでページを再読み込みしてください。

学習機能：
・日本語⇔英語
・タップで反転
・日本語/英語の音声
・自動めくり
・未習得のみ学習
・覚えた/まだ
・ランダム学習用の拡張も可能
