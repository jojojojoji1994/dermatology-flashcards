【皮膚科英単語 PWA】
Windowsで管理し、iPhoneではSafariから使える単語帳です。

■Windowsで試す
1. このフォルダを任意の場所に展開。
2. Pythonが入っている場合、フォルダでコマンドプロンプトを開き
   python -m http.server 8000
   と実行。
3. PCで http://localhost:8000 を開く。

■iPhoneで使う
同じWi-Fi上でWindows PCから配信する場合は、PCのローカルIP:8000をiPhoneのSafariで開けます。
ただし「ホーム画面に追加」や音声・PWAの安定運用にはHTTPSで公開する方法（GitHub Pages等）が推奨です。

■Excel読み込み
Excelの「病名・病態一覧」をCSV UTF-8で保存して、アプリの「CSV読み込み」から選択してください。
列順：章, 章名, 日本語, English, 分類

■主な機能
・618語初期収録
・表裏反転
・タップで反転
・英語音声読み上げ
・自動めくり
・1/2/3/5/10秒設定
・覚えた/まだ
・未習得だけ学習
・学習状況を保存
